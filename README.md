# Photo Date Organizer

브라우저에서 로컬 폴더를 직접 선택해 사진·영상·기타 파일을 날짜 기준으로 정리하는 웹앱입니다.

## 실행

배포된 웹앱을 Chrome 또는 Edge에서 실행합니다. 파일은 서버에 업로드되지 않으며 브라우저의 File System Access API를 사용해 사용자가 선택한 로컬 폴더만 처리합니다.

## 주요 기능

- 연도별 / 월별 / 일별 날짜 정리
- 일별 정리 간격 1~31일 설정
- 사진 / 영상 / 기타 파일 선택
- 미선택 파일 ETC 폴더 분류
- 복사 또는 이동
- 동일 이름 파일 덮어쓰기 또는 번호 추가
- 실행 전 결과 미리보기
- EXIF 촬영일 우선, 정보가 없으면 파일 수정일 사용

## 지원 브라우저

Chrome 또는 Edge 권장.
