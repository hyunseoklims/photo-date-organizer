# 사진 날짜별 정리 도구

## 실행 방법

1. VS Code에서 이 폴더를 엽니다.
2. 터미널에서 아래 명령을 실행합니다.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py photo_date_organizer.py
```

## 사용 방법

- `원본 폴더`: 사진이 들어 있는 폴더를 선택합니다. 하위 폴더도 자동으로 검색합니다.
- `정리할 폴더`: 결과 폴더를 선택합니다. 비워두면 원본 폴더 안에 `날짜별 정리` 폴더가 생성됩니다.
- `정리 기준`에서 연도별, 월별, 일별 중 하나를 선택합니다.
	- 연도별: `2024년`
	- 월별: `2024년/03월`
	- 일별: `2024년/03월/15일`
- `폴더 설정`에서 날짜 형식을 선택할 수 있습니다.
- `폴더명 뒤에 사진 수 표시`를 선택하면 `05일 (12장)`처럼 표시합니다. 기본값은 켜짐입니다.
- `결과 미리보기`는 고정 크기 창에서 스크롤하여 확인할 수 있으며, 다시 열면 이전 결과를 누적하지 않습니다.
- 촬영일 EXIF가 없는 사진은 파일 수정일을 사용합니다.
- 같은 이름의 파일이 있으면 `(2)`, `(3)`을 붙여 덮어쓰지 않습니다.
